# Azeroth Chronicles – Photo tools

🇬🇧 **English** / 🇪🇸 **Español**

Small Windows tools for the **Azeroth Chronicles** addon (*Diario de Aventuras*) for World of Warcraft: Forever.

The game doesn't let addons read your screenshots, so your photos are **"developed"** outside the game: these tools turn your screenshots into images the album can show. CurseForge doesn't allow `.bat` files inside addons, so they're published here.

## Download

👉 **[Download the latest PhotoTools.zip](../../releases/latest)**

## Install (once)

1. Install the **Azeroth Chronicles** addon (from CurseForge).
2. Download **PhotoTools.zip** and extract it into the addon folder:
   `World of Warcraft\<your game folder>\Interface\AddOns\AzerothChronicles`
   (it also works if Windows extracts it into a subfolder inside that folder).
3. Close the game and double-click **`Enable auto develop.bat`**.

That's it. From now on, your photos are developed automatically every time you close the game, even after restarting your computer.

> **"Windows protected your PC"?** That's normal for files downloaded from the internet. Click **More info → Run anyway**. You only have to do it once.

## The tools

| File | What it does |
|---|---|
| `Enable auto develop.bat` | Develops your photos automatically every time you close the game (recommended). |
| `Disable auto develop.bat` | Turns automatic developing off. |
| `Develop photos.bat` | Develops your photos now (close the game first). |
| `Migrate from Diario de Aventuras.bat` | Only if you used the old *DiarioDeAventuras* folder: brings over your memories and photos. |

The files with Spanish names do exactly the same thing.

Your original screenshots stay untouched in the game's `Screenshots` folder.

## 🇪🇸 Español

Herramientas para Windows del addon **Diario de Aventuras** (*Azeroth Chronicles*) de World of Warcraft: Forever.

El juego no deja a los addons leer tus capturas, así que las fotos se **«revelan»** fuera del juego: estas herramientas convierten tus capturas en imágenes que el álbum puede mostrar. CurseForge no permite archivos `.bat` dentro de los addons, por eso están aquí.

### Descarga

👉 **[Descargar el último PhotoTools.zip](../../releases/latest)**

### Instalación (una sola vez)

1. Instala el addon **Diario de Aventuras** (desde CurseForge).
2. Descarga **PhotoTools.zip** y descomprímelo dentro de la carpeta del addon:
   `World of Warcraft\<carpeta del juego>\Interface\AddOns\AzerothChronicles`
   (también funciona si Windows lo descomprime en una subcarpeta dentro de esa carpeta).
3. Cierra el juego y haz doble clic en **`Activar revelado automatico.bat`**.

Listo. A partir de ahora, las fotos se revelan solas cada vez que cierras el juego, incluso después de reiniciar el ordenador.

> **¿Sale «Windows protegió su PC»?** Es normal en archivos descargados de internet. Pulsa **Más información → Ejecutar de todas formas**. Solo la primera vez.

### Las herramientas

| Archivo | Qué hace |
|---|---|
| `Activar revelado automatico.bat` | Revela tus fotos solas cada vez que cierras el juego (recomendado). |
| `Desactivar revelado automatico.bat` | Desactiva el revelado automático. |
| `Revelar fotos.bat` | Revela tus fotos ahora (cierra antes el juego). |
| `Migrar desde Diario de Aventuras.bat` | Solo si usabas la carpeta antigua *DiarioDeAventuras*: trae tus recuerdos y fotos. |

Tus capturas originales se quedan intactas en la carpeta `Screenshots` del juego.
